# 섹션 구분형 (`sectioned`)

## 용도와 선택

문서 종류와 무관하게 큰 섹션을 시각적으로 나누는 디자인이다.
“섹션 구분형으로 만들어 줘”, “이 계획서를 섹션 구분형으로 맞춰 줘”로 선택한다.
미지정 새 문서는 두 미리보기를 보여주고 선택을 안내한다. 문서의 의미·순서·상호참조는 디자인 때문에 바꾸지 않는다.

## 원본 디자인 보존

`styles/sectioned/components.json`은 사용자가 제공한 문서에서 기관명·본문을 제거하고
제목 상자, 섹션 상자, 필요한 서식 리소스와 장식 이미지만 추출한 자산이다.
기본 섹션형은 이 구성요소를 복사하며 비슷한 색상의 새 상자로 재작성하지 않는다.

- 제목: 원본 3행 상자·치수·셀 여백·19pt 설명 제목·24pt 중심 제목·각 문단 정렬을 보존한다.
  상단 파란 띠와 하단 원본 비트맵 장식을 포함하며 기본형의 24mm 높이를 덮어씌우지 않는다.
- 섹션: 원본의 짧은 제목 상자와 각 셀 폭·높이·여백·상하 이중선·그라데이션을 보존한다.
  섹션 번호 HY견명조 21pt와 제목 HY헤드라인M 18pt를 따로 유지한다.
  첫 네 섹션은 원본의 대응 상자를 사용하며 이후에는 마지막 상자를 복제한다.
- 원본 글꼴을 다른 글꼴로 자동 치환하지 않는다. 미설치 환경의 대체 렌더는 원본 글꼴로
  검증한 결과라고 안내하지 않는다. 사용자 환경에 해당 글꼴이 있어야 같은 외형으로 표시된다.
- 소제목은 섹션마다 1부터 시작하고 설명은 ○로 표시한다. 본문은 160%와 문단 묶음 간격을 사용한다.
- 원본 양식·기관명·본문·메타데이터는 공유하지 않는다. 원본 파일은 수정하지 않는다.

## 생성·편집 경로

공통 Markdown 입력: `#` 문서 제목, `##` 큰 섹션, `###` 소제목, `-` 설명 항목.
순번은 입력하지 않는다. 각 섹션에서 소제목 번호를 1부터 생성한다.

```sh
python3 <public-report-style>/scripts/generate_numbered.py content.md --style sectioned --out result.hwpx
```

`--subtitle "설명 제목"`을 추가하면 중심 제목 위에 19pt 설명 제목을 넣는다.
기본 보고서형도 같은 입력에 `--style basic-report`를 지정할 수 있다.
기존 기본형의 중첩 순서 목록 입력은 그대로 지원한다.

생성기는 kordoc 공개 생성 API로 새 파일을 만든 뒤, 자체 생성물에 한정한
`apply_sectioned.py`로 원본 상자·서식 리소스·장식 이미지를 참조 ID 충돌 없이 이식한다.
기존 사용자 파일의 XML을 고치는 정규화 도구가 아니다. 기본형의 제목 높이·번호 후처리를
섹션형에 적용하지 않는다. 스타일 변형은 [스타일 추가 안내](../styles/README.md)를 따른다.
원본 양식 편집은 hwpx-edit로 진행하고 생성 helper를 기존 파일에 적용하지 않는다.

## 검증

validate와 read로 제목·본문 보존, 섹션 로마숫자 순서, 섹션별 소제목 1부터 재시작,
글머리표 후속 줄 정렬과 남은 예시 문구를 확인한다. 렌더에서 두 단 제목·섹션 상자·고아 제목·
표와 쪽 경계를 확인한다. kordoc 근사 렌더와 한글 실물 검증은 구분해 안내한다.
기본형 생성 스크립트와 그 설정 파일은 변경하지 않아 기존 기본값을 유지한다.
