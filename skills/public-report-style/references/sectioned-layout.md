# 섹션 구분형 (`sectioned`)

## 용도와 선택

문서 종류와 무관하게 큰 섹션을 시각적으로 나누는 디자인이다.
“섹션 구분형으로 만들어 줘”, “이 계획서를 섹션 구분형으로 맞춰 줘”로 선택한다.
미지정 시 기본 보고서형을 유지한다. 문서의 의미·순서·상호참조는 디자인 때문에 바꾸지 않는다.

## 디자인 구성

사용자가 제공한 문서에서 확인한 구조를 일반화한 값이다. 정부 의무 양식이 아니다.

- **문서 제목**: 위쪽 설명 제목과 아래쪽 중심 제목을 구분한다. 둘 다 가운데 정렬,
  HY헤드라인M을 우선하며 각각 19pt·짙은 파랑 `#203A7B`, 24pt·파랑 `#3057B9`를 쓴다.
  부제가 필요 없는 문서는 중심 제목만 사용한다. 문서 종류를 제목으로 강제하지 않고,
  원본의 ‘과 업 지 시 서’처럼 글자 사이에 공백을 삽입하는 방식은 일반화하지 않는다.
- **제목 장식**: 상단 파란 띠 `#0080C0`, 하단 가는 파란 장식을 둔다.
  기존 기본형의 24mm 제목 셀 높이 고정은 이 형식에 자동 적용하지 않는다.
  제목 수와 길이에 맞춰 여유를 두되 잘리거나 과도하게 축소되지 않게 한다.
- **큰 섹션**: `Ⅰ. 개요`, `Ⅱ. 추진 내용`처럼 로마숫자와 제목을 함께 표시한다.
  번호 21pt HY견명조, 제목 18pt HY헤드라인M이 원본 기준이다.
  편집 가능한 1행 제목 상자에 상하 파란 이중선(0.5mm), 흰색→연한 파랑
  `#D6EAFE` 배경을 사용한다. 높이는 약 11.3mm를 시작값으로 하며 긴 제목은 확장한다.
  원본 상자 폭은 제목에 따라 달랐다. 페이지 본문 폭 안에서 텍스트가 충분히 들어가게 한다.
- **섹션 내부**: 소제목은 `1.`, `2.`로 표시하고 각 섹션에서 다시 시작한다.
  하위 항목은 필요하면 `가. → 1) → 가)`로 이어가고, 단순 설명 나열은 `○` 글머리표로 쓴다.
  원본의 기호 폰트에 의존하는 사설영역 문자를 복사하지 않는다.
  순번·참조가 필요한 내용은 글머리표로 바꾸지 않는다.
- **문단**: 본문 줄간격 160%, 후속 줄은 본문 시작점에 정렬한다.
  번호/기호와 텍스트는 내어쓰기·탭으로 분리한다. 빈 줄이나 반복 공백으로 정렬하지 않는다.
  소제목과 첫 설명은 가까이, 다음 소제목과 새 섹션 앞은 더 넓게 둔다.
  첫 소제목 앞 0pt, 후속 소제목 앞 9pt, 설명 앞 3pt, 새 섹션 앞 15pt를 초기값으로 사용한다.
  섹션 제목·소제목은 다음 문단과 묶어 고아 제목을 방지한다.
- **표**: 내용에 필요한 경우에만 넣고 기존 기관 표 또는 이 디자인의 파랑 계열에 맞춘다.
  서식의 예시 문구·기관명·사업 내용·금액은 재사용 디자인에 포함하지 않는다.

글꼴이 없으면 설치된 한글 지원 굵은 고딕/명조로 대체하고 대체 사실을 알린다.
그라데이션·이중선을 도구가 재현하지 못하면 연한 단색 배경·실선으로 조용히 바꾸지 말고,
지원되는 경로로 구현하거나 차이를 결과 안내에 명시한다.

## 생성·편집 경로

이 문서는 디자인 명세이며 `generate_numbered.py`의 새 CLI 옵션이 아니다.
`--preset report`는 **기본 보고서형 생성 경로**이므로 이것만 실행하고 섹션 구분형이라 하지 않는다.

1. 내용을 `문서 제목 / 선택적 설명 제목 / 섹션 / 소제목 / 번호 항목 또는 설명 목록 / 표`로 구성한다.
   입력 Markdown에서 `#`는 문서 제목, `##`는 큰 섹션, `###`는 소제목으로 구분할 수 있다.
   출력에서 로마숫자와 소제목 순번은 각각 한 번만 부여한다.
2. 사용자가 제공한 해당 디자인 원본이 있으면 `hwpx-edit`의 읽기·양식 수정 경로로
   제목 상자와 섹션 상자를 보존한다. 새 섹션 상자는 `table-copy`, 제목 교체는 `table-set`을
   사용하고 원본의 남는 본문은 제거한다. 원본 파일은 보존하고 새 파일로 저장한다.
3. 원본 없이 생성할 때는 위 명세로 편집 가능한 제목·섹션 상자를 `table-build` 또는
   설치된 python-hwpx 공개 API로 구성한다. 정확한 현재 호출 규격은 hwpx-edit 참조를 읽는다.
   문서 전체를 이미지로 만들지 않는다. 원본 파일이나 개인 경로가 설치의 필수 조건이 되어서는 안 된다.
4. 기본형 전용 `fix_title_height.py`와 `apply_paragraph_spacing.py`를 완성된 섹션형에
   일괄 적용하지 않는다. 이 형식의 역할별 간격과 섹션 내부 번호 재시작을 적용한다.

## 검증

validate와 read로 제목·본문 보존, 섹션 로마숫자 순서, 섹션별 소제목 1부터 재시작,
글머리표 후속 줄 정렬과 남은 예시 문구를 확인한다. 렌더에서 두 단 제목·섹션 상자·고아 제목·
표와 쪽 경계를 확인한다. kordoc 근사 렌더와 한글 실물 검증은 구분해 안내한다.
기본형 생성 스크립트와 그 설정 파일은 변경하지 않아 기존 기본값을 유지한다.
